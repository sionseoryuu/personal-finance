# Personal Finance Intelligence — Panduan

## 1. Pasang di GitHub Pages
Unggah 6 file ini ke satu repo, semuanya di folder utama (jangan di dalam folder): `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
1. github.com, tekan **+**, lalu **New repository**. Pilih **Public**, lalu **Create repository**.
2. **Add file**, lalu **Upload files**. Pilih keenam file, lalu **Commit changes**.
3. **Settings**, lalu **Pages**. Source: **Deploy from a branch**, branch **main**, folder **/ (root)**, lalu **Save**.
4. Tunggu 1-2 menit. Alamatnya `https://USERNAME.github.io/NAMA-REPO/`.

## 2. Instal di ponsel
- **Android (Chrome):** buka alamat di atas, tekan menu ⋮, lalu **Instal aplikasi** atau **Tambahkan ke layar utama**. Atau buka Pengaturan di aplikasi, lalu tekan **Instal aplikasi**.
- **iPhone (Safari):** tekan tombol **Bagikan**, lalu **Tambah ke Layar Utama**.
Setelah terpasang, aplikasi terbuka layar penuh dan tetap bisa dipakai tanpa internet. Hanya grafik yang butuh koneksi pada pembukaan pertama.

## 3. Cara memakai
1. **Akun:** tambah dompet atau rekening dengan saldo awal. Ini wajib sebelum mencatat.
2. **Catat transaksi:** tekan tombol **+**. Pilih Pengeluaran, Pemasukan, Refund (uang kembali), atau Penyesuaian (mencocokkan saldo). Tombol "Transaksi cepat" mengisi ulang transaksi yang sering dibuat. **Input cepat** di menu Transaksi membaca kalimat seperti "makan siang 25rb pakai cash kemarin" dan meminta konfirmasi dulu.
3. **Transfer:** menu Akun, lalu Transfer. Transfer tidak dihitung sebagai pemasukan atau pengeluaran. Biaya transfer dicatat sebagai pengeluaran.
4. **Ubah, hapus, duplikasi:** tombol ✏️, 🗑, dan 📄 di daftar transaksi. Ketuk sebuah transaksi untuk melihat detail dan riwayat perubahan.
5. **Anggaran:** pilih kategori (atau Semua pengeluaran), periode, dan batas. Buat anggaran Semua pengeluaran agar "Boleh dibelanjakan hari ini" muncul.
6. **Rencana:** tagihan (Bayar baru membuat pengeluaran), utang, piutang (bisa dicicil), dan target tabungan.
7. **Analitik, Laporan, Kalender, Asisten:** semuanya dihitung dari transaksi Anda. Asisten berbasis aturan, bukan AI sungguhan. Laporan bisa diekspor CSV atau dicetak ke PDF.
8. **Pengaturan:** ganti tema (Fintech, Noir & Gold, Classic), mode gelap, mode privasi, kategori, foto profil, dan format tanggal/angka.

## 4. Backup (penting)
Data tersimpan di browser perangkat itu saja, bukan di GitHub. Jika data browser dihapus, data hilang. Gunakan **Pengaturan, lalu Export backup JSON** secara berkala. Untuk pindah perangkat, pakai **Import backup** di perangkat baru.

## 5. Jika ada masalah
- **Tampilan lama setelah update:** tutup aplikasi lalu buka lagi dua kali, atau hapus data situs di pengaturan browser. Backup dulu.
- **Grafik kosong:** perlu internet saat pertama dibuka.
- **Tombol Instal tidak muncul:** pastikan dibuka lewat alamat https, bukan file lokal.
